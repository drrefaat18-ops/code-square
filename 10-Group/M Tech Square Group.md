# M Tech Square Group

## For future Claude

Code Square does not exist alone — it is one entity inside the **M Tech Square** group ("Beyond Squares"). Read this when anything touches the parent brand, a sister company, shared infrastructure, or the question "who actually owns what". The group is simultaneously Code Square's **biggest strategic asset** (a permanent in-house case-study factory and a captive first client) and a **liability** (Code Square has no domain, no independent identity, and inherits the parent's broken website). Much of the ownership structure is `TBD` — see `[[Open Questions and Decisions Needed]]` I9.

## The "Universe" concept (stated — from Code Square's own published case study)

Code Square designed the group website around a single organising idea, described in its Facebook case study:

> كل كيان له عالمه، وطبيعته، وجمهوره… فالـPlanets هنا مش مجرد شكل جمالي، هي انعكاس لفكرة إن كل كيان له قيمة ودور مختلف، لكن في النهاية كلهم جزء من Universe واحد.

- **M Tech Square = the Universe.** Space as the visual concept, so many entities can coexist in one place while each keeps its own room.
- **Each entity = a planet** with its own theme, visual language, and experience.
- The stated message: **"مختلفين… لكن مش منفصلين"** — different, but not separate.
- Per-entity treatments: Code Square got 3D models + animation (*the site itself is the proof of capability*); Techno Square got illustration + infographics + the تاتا mascot (*a student's journey, not an academic page*); Online Techno Square got glassmorphism + holographic elements (*distance still deserves an experience*).

**Why this matters commercially:** this is a genuinely sophisticated piece of information architecture and brand strategy, and it is Code Square's own work. It is the single best demonstration that the company thinks structurally rather than decoratively. It should be a flagship case study — see `[[Case Study - M Tech Square Website]]`.

## Code Square's relationship to the group

### Asset side
| Asset | Value to Code Square |
|---|---|
| **Captive first client** | The group website and the Techno Square platform are real, shipped, complex projects — delivered without needing to win a competitive pitch. |
| **Permanent case-study factory** | Internal projects need no client permission to publish. Code Square can produce proof on its own schedule. Compare this to `[[Case Study - El Shoush Travel System]]` and `[[Case Study - Osama Sakr Manning Agency]]`, both of which are blocked on permission. |
| **A live education product** | Techno Square + Online Techno Square is a working platform, mobile app, dashboard, and enrolment flow — a demo-able, sellable pattern for the entire education segment. |
| **Cross-sell surface** | The group's own published problem statement was that clients of one entity never learned the others existed. That cuts both ways: every Techno Square student's parent, and every Digital Square client, is a warm audience for Code Square. |
| **Shared credibility** | A group presents larger and more permanent than a lone agency — relevant when selling to enterprises and government. |

### Liability side
| Liability | Cost to Code Square |
|---|---|
| **No independent domain** | Code Square lives at `mtechsquare.com/code-square/`. All SEO equity accrues to the parent; brand recall is diluted; the CTA is clumsy. See `[[Open Questions and Decisions Needed]]` I1. |
| **Inherited technical failure** | The expired TLS certificate and the non-rendering Angular site are the *parent's* infrastructure. Code Square's credibility is hostage to a system it may not control. See `[[Website and Technical Audit]]`. |
| **Inherited metadata** | `/code-square/` has no page-level title or description — a search result or social share says "M Tech Square Group", never "Code Square". |
| **Identity dilution** | Two visual systems now exist under one name (group navy + gold vs Code Square's Facebook violet-on-black). See `[[Visual Identity]]`. |
| **Unclear P&L and authority** | Unknown who decides Code Square's budget, pricing, and hiring. This blocks almost every operational decision. |

## Open questions specific to the group

1. What is the formal legal relationship — subsidiary, division, brand, or partnership? Who owns Code Square's P&L?
2. Who controls the `mtechsquare.com` domain, DNS, hosting, and certificates? Can Code Square fix its own site, or must it request it?
3. Is Code Square permitted to buy and operate an independent domain?
4. What is the named medical entity in the group, and does it open the healthcare beachhead?
5. What are Digital Square, M Square, and M Nature — and does Digital Square compete with, or feed, Code Square's marketing function?
6. Do the sister entities pay Code Square, or is internal work unbilled? This materially changes the revenue picture and the case-study framing.
7. Is there a group-level brand guideline that governs Code Square's identity?

All are mirrored in `[[Open Questions and Decisions Needed]]`.
