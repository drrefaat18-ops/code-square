## 4. Our approach — mapped to the four-phase methodology

*(Canonical model from the Code Square website: التأسيس → المعمارية → الهندسة → الإطلاق والتطوير.)*

**التأسيس — Discovery.** `❓ NEEDS FROM FOUNDER:` How did the engagement start — referral, inbound, existing relationship? What was scoped in and, importantly, what was deliberately left out of version one?

**المعمارية — Architecture.** Evidenced from the site description: the system is **comprehensive** (`نظام شامل`), covering both **booking and management** for agencies, and it was designed **multi-language** from the outset with **Maps API integration**. Multi-language in a travel system is an architecture decision, not a feature — it implies the client serves customers across more than one language.

`❓ NEEDS FROM FOUNDER:` Which languages? Which Maps provider (Google Maps, Mapbox, other), and what is the map actually used for — route display, pickup points, destination selection, driver tracking?

**الهندسة — Engineering.** `❓ NEEDS FROM FOUNDER:` What stack? Web only, or is there a mobile app? Is there a customer-facing side, or is it internal staff only? Are payments handled in the system?

**الإطلاق والتطوير — Launch & Iterate.** `❓ NEEDS FROM FOUNDER:` When did it go live? Is it in daily use today? What has been added since launch?
